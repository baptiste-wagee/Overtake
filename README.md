# 🏎️ Overtake

**Overtake** est un projet personnel que j'ai développé afin de combiner deux de mes passions : **la Formule 1** et le **développement web**.

Le site a été entièrement réalisé en **HTML**, **CSS** et **JavaScript**, avec pour objectif principal de progresser en développement front-end tout en créant un site sur un sujet qui me passionne.

## 🌐 Liens

👉 https://baptiste-wagee.github.io/Overtake/index.html

## 📖 À propos du projet

Overtake est un site web dédié à l'univers de la Formule 1.  
Ce projet me permet de mettre en pratique les notions de développement web apprises au cours de ma formation et d'expérimenter de nouvelles idées d'interface et d'animations.

L'objectif n'est pas seulement de créer un site fonctionnel, mais également de développer mes compétences en :

- HTML5
- CSS3
- JavaScript
- Responsive Design
- Organisation d'un projet web
- UI / UX Design

## 🚀 Technologies utilisées

- 🌐 HTML
- 🎨 CSS
- ⚡ JavaScript

## 🎯 Objectifs

- Développer un site moderne sur la Formule 1
- Améliorer mes compétences en développement front-end ainsi qu'en design
- Découvrir de nouvelles techniques de mise en page et d'animations et de données 
- Construire un projet personnel que je pourrai enrichir au fil du temps
